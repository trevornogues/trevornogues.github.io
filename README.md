# trevornogues.github.io

User GitHub Pages site for <https://trevornogues.github.io>.

The personal site itself is the Next.js app on Vercel
(<https://trevvnog.vercel.app>). This repo exists so the `*.github.io` host
answers over HTTPS with GitHub Pages' certificate and HSTS, and points
visitors at the real site.

Pages source: branch `main`, folder `/`.
